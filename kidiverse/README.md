# The Kidiverse site

The Kidiverse landing page **and every public Kidiverse document** — the one and only copy.
The app (github.com/nexomalabs/kidiverse, not public) links here from its Settings and keeps no
copy of its own.

```
kidiverse/
  index.html          the landing page, hand-written (build_docs.py never overwrites it)
  styles.css          its tokens, both themes, all layout
  main.js             theme, reveals, the sign-up form, and the drawn scenes
  app.json            SOURCE  metadata for tools/build_docs.py
  PRIVACY.md          SOURCE  -> privacy.html   /kidiverse/privacy
  TERMS.md            SOURCE  -> terms.html     /kidiverse/terms
  FAQ.md              SOURCE  -> faq.html       /kidiverse/faq
  SUPPORT.md          SOURCE  -> support.html   /kidiverse/support
  SAFETY.md           SOURCE  -> safety.html    /kidiverse/safety
  LEGAL.md            SOURCE  -> legal.html     /kidiverse/legal
  LICENSES.md         GENERATED by the app repo's `npm run licenses:build` -> licenses.html
  assets/
    docs.css          the document pages' theme (this page's tokens)
    brand.svg, favicon.svg   the mark and tab icon the document pages use
    brand/            the page's icons (the tab mark; the mascot face for home screens)
    worlds/           world art        } written by the app repo's
    mascot/           mascot poses     } `npm run website:build`
    og-card.jpg       the 1200x630 card link previews show
```

## The documents

Edit the Markdown, then run `python3 tools/build_docs.py` from the repository root and commit
both the `.md` and the `.html` (see `tools/README.md`). Never edit a generated `.html`.

Every sentence is a claim about the app as it is built today, and the app repository checks
them: `npm run verify:legal` there (with this repository cloned beside it) fails if

- the privacy policy or this page stops repeating the app's camera disclosures word for word;
- a camera claim that has been ruled misleading appears anywhere here;
- something the build does not have is described (the retired camera cut-out, reduced flash,
  session length, slots, the Kids Category), or something it does have is denied (advertising,
  on-device storage, a second permission);
- a document has a placeholder or promises a reply time;
- `LEGAL.md` lacks `## Address`, `## Represented by` or `## Registration`. **It does today** —
  these are the publisher details only Nexoma Labs can supply, needed for the EU legal notice.

Run it before submitting the app to either store, and after changing anything here.

## Publishing

Every path in the page is relative, so the folder can be served from any
sub-path without editing anything — with three exceptions, all of them in the
first fifteen lines of `index.html`: `canonical`, `og:url` and `og:image` are
absolute, because link scrapers do not resolve relative paths. If the site
lands anywhere other than `https://www.nexomalabs.com/kidiverse/`, change those
three lines and nothing else.

Nothing is minified. The whole page is about 40 KB of text plus the art, and
keeping it readable is worth more than the bytes.

## Where the content comes from

The copy is not invented marketing. It is drawn from the product's own
documents, and two parts of it are quoted rather than paraphrased:

- **The four camera disclosures** in the *What the camera does* section are the
  words the app itself shows a parent, from `src/consent/copy.ts`. If that file
  changes, this page changes with it. Do not reword them here to make them
  shorter — they exist in that shape because a headline that says less than its
  detail is how a disclosure becomes technically complete and practically
  misleading.
- **The status ledger** is the honest split the team keeps internally. In
  particular: **no frame-rate or latency figure appears anywhere on this page,
  because none has been measured on a named device.** Adding one is not a copy
  decision; it requires a measurement first.

The app repository's `npm run verify:legal` scans this folder's `.html` and `.md`
files for wording about the camera that has been ruled misleading. That is deliberate: marketing copy is exactly where such a claim
tends to reappear in a shortened, friendlier form. If a change here fails that
check, the fix is the sentence, not the check. Keep parent-facing sentences in
`index.html`, where the scan reaches them, rather than in `main.js`, where it
does not.

## The two scenes are drawn, not recorded

`main.js` draws the weather and the anatomy figure with Canvas 2D from the same
five gestures the app recognises. There is no video and no screenshot, so the
demo cannot quietly drift out of date the way a recording does.

Two behaviours are carried across from the app on purpose:

- **The lightning wash is capped at three flashes a second** (`MIN_STRIKE_GAP`),
  the same photosensitivity limit the app enforces in world logic.
- **`prefers-reduced-motion` removes the flash entirely**, not just slows it — a
  full-screen flash is the specific thing that setting exists to prevent. The
  scenes still respond to a click; they simply do not animate.

## The early-access form

Out of the box the form has no server. It validates the address and then opens a
pre-filled message to `EARLY_ACCESS_EMAIL` — which works on a static host with
nothing running behind it.

To collect addresses properly, set `EARLY_ACCESS_ENDPOINT` at the top of
`main.js` to a URL that accepts `POST {"email": "...", "source": "kidiverse-site"}`.
The form switches to it automatically and falls back to the mail app if the
request fails.

**Confirm `EARLY_ACCESS_EMAIL` before publishing.** It is currently
`hello@nexomalabs.com`, which was assumed rather than given.

## Regenerating the images

The source art lives in the app repository. From there, with this repository cloned beside it:

```bash
npm run website:build     # assets/worlds/, assets/mascot/, assets/og-card.jpg, assets/{brand,favicon}.svg
npm run licenses:build    # LICENSES.md — then run tools/build_docs.py here
npm run website:serve     # http://localhost:4321/kidiverse/
npm run website:preview   # flattens this folder into one shareable HTML file
```

`website:build` needs Python's Pillow with WebP support. The older `valley-*.jpg` used by the
weather demo predate it and are left as published.
